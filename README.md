# 💡 Algoritmos e Lógica de Programação — UC02 (Senac EAD)

Repositório dedicado aos exercícios e atividades práticas desenvolvidos na Unidade Curricular 02 (**Desenvolver Algoritmos**) do curso Técnico em Desenvolvimento de Sistemas no Senac EAD.

---

## 🎯 Conceitos Praticados

- **Lógica de Programação Básica:** Variáveis, tipos de dados, entrada e saída (`leia` / `escreva`).
- **Estruturas Condicionais:** Tomada de decisão encadeada (`se`, `senao se`, `senao`).
- **Estruturas de Repetição:** Laços de controle (`para`).
- **Estruturas de Dados:** Manipulação de vetores (arrays).
- **Ferramenta:** Portugol Studio.

---

## 📂 Atividades Desenvolvidas

### 🔹 Atividade 01 — Sistema de Sugestão de Pratos e Descontos
- **Descrição:** Algoritmo de tomada de decisão para um restaurante. O sistema coleta as preferências do cliente (dieta e restrições) para sugerir o prato ideal e calcula descontos de acordo com a forma de pagamento.
- **Arquivo:** [`sugestaoPratos_DiegoRodrigues.por`](./sugestaoPratos_DiegoRodrigues.por)

### 🔹 Atividade 02 — Controle de Vendas e Descontos com Vetores
- **Descrição:** Sistema de caixa para loja de comércio. Utiliza vetores para cadastrar múltiplos clientes e seus respectivos gastos, aplica descontos condicionais acima de determinado valor e gera um relatório com o total arrecadado e total de clientes beneficiados.
- **Arquivo:** [`descontoLoja_DiegoRodrigues.por`](./descontoLoja_DiegoRodrigues.por)
